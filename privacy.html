Privacy Policy

rclone-backup is a personal application operated by a single user for local backups.

Data Access

The application requests read-only access to the owner's Google Drive files.

Data Usage and Storage

Google Drive data is accessed only to create backup copies on the owner's local computer.

Data Sharing

The application does not sell or share Google Drive file contents with third parties.

Authentication

OAuth credentials and tokens are stored locally and are not published on this website.

Access Revocation

The owner can revoke access at any time through Google Account security settings.
